視差捲動效果

作者：Vineet Kumar

什麼是視差捲動？

視差捲動是一種網頁設計技巧，讓網站的背景以比前景更慢的速度移動，當訪客向下捲動時便會形成 類似 3D 的深度感，帶來更沉浸的瀏覽體驗。視差效果源自光學錯覺：人眼會覺得較近的物體比遠方 的物體大，並感知遠處的物體移動較慢。這種錯覺在各種媒介中都被運用，營造逼真的效果。它最早 被應用在傳統動畫中，早期的迪士尼《白雪公主與七矮人》以及《超級瑪利歐》等遊戲都採用了視差 技術。隨著 CSS 和 HTML 的進步，視差效果才演變成現今網頁設計的樣貌。

首批在瀏覽器中實作視差捲動的案例是由網頁開發者 Glutnix 在 2007 年於部落格分享，提供了 使用 JavaScript 和 CSS 2 的範例程式碼與示範，當時甚至支援 Internet Explorer 6 以及同年代 的其他瀏覽器。不過直到 2011 年，伴隨 HTML5 與 CSS3 推出的語法，這項技術才在網頁設計圈 盛行起來。支持者認為，視差是擁抱網頁流動性的簡單方式，能用來提升互動並改善整體體驗。 然而，普渡大學在 2013 年發表的研究指出：「……雖然視差捲動強化了使用者體驗的部分面向，但 並不一定能提升整體的使用者體驗。」


為什麼要使用視差圖像？

    設計師應該嘗試視差圖像有兩個主要原因：

  • 有助於說故事

    視差圖像非常適合用來敘事。好的設計都是為了溝通；在設計網站時，我們希望與訪客交流， 並說出關於產品、服務或品牌的精彩故事。視差捲動能讓訪客沉浸在獨特的線上體驗中，甚至 可以打造單頁網站，讓使用者不用切換頁面就能閱讀完整的品牌故事。

  • 能提升使用者互動

    視差圖像也能用來提升互動。降低跳出率是網站設計的重要目標之一。跳出率表示使用者只看了 一頁就按下「返回」或關閉頁籤的比例，過高會影響搜尋排名，因此任何能降低跳出率的作法都 值得嘗試。精心打造的視差頁面能帶來更動態的體驗，讓使用者願意停留更久。


如果想在網站加入視差捲動效果，請參考以下建議：

  • 選擇性地使用

    將視差效果用在特定元素上會比整站到處使用更有力。可以放在頁首、標題或僅限首頁，讓它 成為加分的設計，而非分散注意力的噱頭。

  • 壓縮圖片

    視差捲動常使用多種媒體檔與 CSS 圖形來營造深度感，但你不會希望龐大的圖片拖慢載入， 影響效能與使用者體驗，因此記得壓縮圖片。

  • 善用色彩

    視差不只關於前景與背景的圖像，也與色彩有關。背景可以使用較低彩度的色調，前景則使用 更鮮明的色彩，能進一步提升深度效果。
